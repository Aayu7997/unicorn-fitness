## Animation Specifications

### 58+ Cinematic Animations

#### Scroll-Triggered (GSAP ScrollTrigger)
1. **Stagger Reveals** - Items cascade in with delay
2. **Blur Reveals** - Fade from blur to clarity
3. **Scale Reveals** - Grow from 0.9 to 1.0
4. **Parallax Effects** - Depth through movement
5. **Clip Path Reveals** - Directional reveals
6. **Pin Sections** - Sticky scroll effects

#### Interactive (Framer Motion)
1. **Magnetic Buttons** - Cursor tracking
2. **Hover Lifts** - Cards rise on hover
3. **Image Zooms** - Smooth scale on interaction
4. **Text Splits** - Character-by-character reveals

#### Continuous (Loop Animations)
1. **Floating Elements** - Gentle bob motion
2. **Gradient Rotations** - Color cycling
3. **Pulsing Shadows** - Glow effects
4. **Rotating Elements** - Continuous spin

#### Easing Curves Used
```
Back Out:       [0.34, 1.56, 0.64, 1]      (Apple style)
Power Out:      power3.out                 (Nike style)
Smooth:         [0.25, 0.46, 0.45, 0.94]   (Google style)
Elastic:        back.out(1.7)              (Samsung style)
```

### Prerequisites

## Troubleshooting

### Issue: Animations lag on mobile
**Solution**: 
- Reduce animation complexity
- Use `will-change: transform;` on animated elements
- Test on actual device, not browser mobile simulator

### Issue: Images don't load
**Solution**:
- Check image paths in `/public/images/`
- Verify image formats (JPG, PNG, WebP)
- Use Next.js Image component for optimization

### Issue: Fonts look wrong
**Solution**:
- Clear browser cache
- Check font imports in layout.tsx
- Verify font-sans class applied to body

### Issue: Colors don't match brand
**Solution**:
- Update CSS variables in globals.css
- Check Tailwind config for color overrides
- Verify theme colors in design tokens
