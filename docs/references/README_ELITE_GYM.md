## 🔧 Customization Guide

### Change Colors
Edit `/app/globals.css`:
```css
@theme inline {
  --primary: #your-color;
  --accent: #your-accent;
}
```

### Modify Animation Speed
Edit `/lib/animations.ts`:
```typescript
duration: 0.8  // Increase for slower
stagger: 0.12  // Increase for more spacing
```

### Adjust Easing
Common curves:
```typescript
[0.34, 1.56, 0.64, 1]  // Back out (bounce)
[0.25, 0.46, 0.45, 0.94]  // Smooth professional
'power3.out'  // Strong deceleration
'back.out(1.7)'  // Overshoot bounce
```

### Add New Section
1. Create component in `/components/`
2. Add scroll animations in component
3. Import in `/app/page.tsx`
4. Insert in page flow
5. Style with Tailwind + globals
